# Kreativicon ISP Order & Project Management System

Enterprise-level web application for managing ISP customer orders, installations, activations, engineer project tracking, reporting, email summaries, and management dashboards. Fully aligned with the source of truth Excel workbook `KI_Orders_with_Summary_Updated (4).xlsx`.

---

## Technical Architecture

- **Frontend**: React + TypeScript + Tailwind/CSS System + ApexCharts
- **Backend REST API**: Laravel 12 (REST API Engine)
- **Database**: PostgreSQL (Relational Normalized Schema)
- **Authentication**: JWT / Role-Based Access Control (RBAC)
- **Excel Engine**: Column mapping preview, duplicate detection, multi-sheet XLSX export
- **Containerization**: Docker & Docker Compose
